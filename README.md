# Sarkomet A.Ş. Elektrolitik Bakır Sanayi ve Ticaret A.Ş. -  İnsan Kaynakları ve Kalite Yönetim Portalı 

Sarkomet A.Ş. Elektrolitik Bakır Sanayi ve Ticaret A.Ş. adlı kurgusal bir şirket için geliştirilmiş, İnsan Kaynakları ve Kalite Yönetim Portalı web tabanlı bir portaldır. Bu proje bağımsız bir
eğitim/portföy projesidir; kurgusal veriler içerir ve gerçek bir şirketin
verilerini veya iş süreçlerini yansıtmaz.

## Kurulum

**Gereksinimler:** Node.js

1. Bağımlılıkları yükleyin:
   `npm install`
2. Uygulamayı çalıştırın:
   `npm run dev`

## Build

`npm run build` komutu ile üretim (production) derlemesi `dist/` klasörüne oluşturulur.
